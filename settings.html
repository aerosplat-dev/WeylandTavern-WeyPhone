WeyPhone
When on, a tethered WeyPhone conversation's content also flows INTO the main roleplay chat's next reply (e.g. arranging to meet someone over text, then having the roleplay know about it) — off by default since this can affect the main roleplay's own history/behavior. Nothing is ever permanently written to your saved chat; turning this off (or untethering a conversation) removes its effect immediately. When on (and Bi-directional Tethering is also on), a character texting you inside a main roleplay reply is pulled out of that message and delivered as real WeyPhone messages in a thread with them — new threads start tethered so they round-trip back into the story. Requires Bi-directional Tethering; turning this on also disables streaming (the text must be fully settled to parse).
Teach WeyPhone the alternate names your characters use for you (e.g. juicebox, pookie, wolfmeat) and an optional custom nickname per contact, so it recognizes them when capturing texts from the roleplay. juicebox/pookie/wolfmeat are always included.

Generation Connection

Pick a Connection Profile for WeyPhone's own generation (Messages, The Chronicle, Discord, Yik Yak, Twitter). Leave unset to keep using whatever profile/API is currently active for the main roleplay chat. Manage profiles in the Connection Manager panel above. Overrides just the model WeyPhone generates with, independent of the profile above — useful for running WeyPhone on a different model than the main roleplay chat. Leave blank to track the main chat's active model automatically.
